# DOCUMENT 10.3 — USER DOCUMENTATION & ETHICAL-DASHBOARD GUIDE

**System:** Aevum · **License:** `LicenseRef-AVL-2.0` · **Tier:** 10 · **Maturity:** InDevelopment · **© Maher**

User-facing documentation and the ethical-dashboard guide, written in plain language, accessible (WCAG-conformant), and multi-language (with the low-literacy voice UX for feature-phone users, document 6.3). It covers: managing identities and the rung ladder; passkeys, recovery codes, and *mandatory social recovery* (the high-friction guardian-based path, never a low-friction reset); setting the user-sovereign ethical filter and understanding contestable labels; reading the activity log and decision receipts; and understanding what each currency *is* (including the honest scope statements — $FLUX is a losing trade to hold idle, $PEG+ is experimental, contribution credits can never be taken from you). This document carries a special responsibility flagged repeatedly: the user-sovereign filter places real responsibility on users, so the docs and defaults must keep sovereignty from becoming an inattention-trap — sensible, clearly-explained defaults and contestable labels are themselves a safety feature. Honest caveat: the hardest documentation problem is making honest partial-coverage and the custodial offline trade-off *understandable* to non-experts without either overwhelming them or hiding the trade — this is an open usability-meets-ethics problem (InDevelopment).
