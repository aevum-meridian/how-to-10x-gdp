# DOCUMENT 10.2 — ECONOMIC AGENT SDK

**System:** Aevum · **License:** `LicenseRef-AVL-2.0` · **Tier:** 10 · **Maturity:** Research · **© Maher**

A developer toolkit for building bots, DApps, and agents that interact with the body's currencies (automated treasury, carbon-adjusted invoicing, conditional transfers, $UNA-based conditional cash transfers). The SDK is single-call where possible (propose an intent; the body validates and confirms) with an escape hatch (verbose mode to inspect what will happen). It is bound by the same floors as everything else: an SDK-built agent has no more authority than the proposing party (it can propose, never author a Meridian balance change); it cannot place ML on the trusted path (A-§C.12 — an agent may propose or gate, never execute a rights-affecting decision autonomously); and it must surface maturity labels honestly. First-class machine/agent identity is itself a governed feature (an agent acts on behalf of a verified principal, never as an unaccountable autonomous actor). Honest caveat: an agent SDK that lets autonomous agents move value is exactly where "ML on the trusted path" would sneak in, so the SDK structurally confines agents to proposing and gating, and the architectural test that forbids ML execution applies to SDK-built agents too.
